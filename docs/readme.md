# res-downloader

res-downloader 是一款适用于 Windows、macOS 和 Linux 的网络资源发现与下载工具，可以识别和下载常见的视频、音频、图片、文档、M3U8 与直播资源。

## 主要功能

- 从浏览器、手机或桌面应用中发现网络资源。
- 通过插件支持微信视频号、抖音等特定站点。
- 下载普通文件、HLS、多轨资源和合集。
- 配置 FFmpeg 后支持媒体合并、格式转换和直播录制。
- 在任务中心管理下载进度和历史记录。
