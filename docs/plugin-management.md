# 插件管理

插件用于改善特定网站的资源识别和下载效果。应用包含部分官方插件，也可以安装社区插件。

## 安装插件

打开“插件管理”，可以从扩展商店安装，也可以选择本地 ZIP 文件。

安装前请确认开发者、访问域名和权限符合插件用途。社区插件由第三方提供，不代表经过官方安全审核。

## 启用和设置

- 禁用插件后，它不会继续处理新资源。
- 部分插件提供画质、抓取范围等设置。
- 修改设置后，按页面提示保存或重新加载。

## 更新和卸载

有新版本时，插件卡片会显示更新提示；扩展商店中的可更新插件会优先显示。

更新失败时可以重试或回滚到上一版本。卸载插件不会删除已下载文件。

## 插件无法使用

依次检查：

1. 插件是否已经启用；
2. 插件卡片是否有错误提示；
3. 页面是否重新打开并产生了新请求；
4. 插件设置是否正确；
5. 目标网站是否已经发生变化。

仍无法解决时，请向插件开发者反馈应用版本、插件版本、复现步骤和错误提示。请先隐藏 Cookie、账号等隐私信息。

开发插件请查看[插件开发指南](plugins.md)。
