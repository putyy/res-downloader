# 快速开始

## 1. 安装应用

从 [GitHub Releases](https://github.com/putyy/res-downloader/releases) 下载适合当前系统的安装包，完成安装后启动应用。

## 2. 安装证书

首次启动时，按引导安装当前电脑的证书，并完成系统授权。以后也可以在“系统设置 → 证书”中操作。

手机抓取需要另外下载证书，并在手机系统中安装和信任。

## 3. 开启抓取

返回“获取资源”，点击“开启抓取”，然后打开需要捕获的网页或应用。资源出现后可以预览、复制链接或下载。

如果特定网站识别不完整，可以到“插件管理”中安装对应插件。

## 4. 查看下载

在“下载任务”页面查看进度，并使用任务上提供的暂停、继续、取消或重试操作。

遇到问题请查看[常见问题](troubleshooting.md)。
