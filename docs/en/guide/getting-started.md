# Quick Start

## 1. Install the app

Follow the [installation guide](installation.md) to download and install the version for your system, then launch the app.

## 2. Install the certificate

On first launch, follow the instructions to install this computer's certificate and approve the system authorization request. You can also do this later under **Setting → Certificate**.

To capture traffic from a phone, download the certificate separately and install and trust it in the phone's system settings.

## 3. Start capturing

Return to **Intercept**, click **Start Grabbing**, and open the website or app you want to capture. Once resources appear, you can preview them, copy their links, or download them.

If a particular site is not detected correctly, install its dedicated plugin under **Plugins**.

## 4. Manage downloads

Open **Downloads** to track progress and use the pause, resume, cancel, or retry actions available for each task.
