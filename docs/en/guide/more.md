# Tips

## Filter resources

Use type and keyword filters when the list gets long. Clearing captured resources does not delete download tasks or downloaded files.

## Batch operations

The resource list supports batch downloads, import, and export. Exports contain captured resource records only.

## Copy links

Some links contain temporary signatures or login information and may expire soon after being copied. Capture them again when needed.

## Decrypt WeChat Channels files

Files downloaded through the app are processed automatically. If you downloaded a file with another tool, choose **Decrypt local video** from the corresponding resource's menu.

## Apply settings

Most settings are saved immediately. Restart the app after changing the listen address or port.
