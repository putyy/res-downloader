# Feature Walkthrough

## Capture web resources

1. Make sure the certificate is installed.
2. Click **Start Grabbing**.
3. Open the target page and play or view the content.
4. Return to the resource list to filter, preview, or download.

Some sites require a dedicated plugin to be installed under **Plugins** first.

## Capture from a phone

Set the listen address to `0.0.0.0` and connect the phone and computer to the same network. Configure the phone to use the computer's proxy, then install the current certificate on the phone.

## Manage downloads

After creating a task, open **Downloads** to see its progress and available actions.

## Use plugins

Plugins can improve detection and downloading for specific sites. Before installing a third-party plugin, make sure you trust its developer and requested permissions.
