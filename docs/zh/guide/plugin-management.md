# 插件管理

插件用于改善特定网站的资源识别和下载效果。应用包含部分官方插件，也可以安装社区插件。

## 安装插件

打开“插件管理”，可以从扩展商店安装，也可以选择本地 ZIP 文件。

可通过搜索和排序找到需要的插件并安装。安装前请确认开发者、访问域名和权限符合插件用途。社区插件由第三方提供，不代表经过官方安全审核。

## 启用和设置

- 禁用插件后，它不会继续处理新资源。
- 部分插件提供画质、抓取范围等设置。
- 修改设置后，按页面提示保存或重新加载。
- 插件调试日志默认关闭；提供“启用日志”开关的插件可在排查问题时开启，完成后关闭。

## 更新和卸载

有新版本时，插件卡片会显示更新提示；扩展商店在默认排序下会优先显示可更新插件。

更新失败时可以重试或回滚到上一版本。卸载插件不会删除已下载文件。

## 插件无法使用

依次检查：

1. 插件是否已经启用；
2. 插件卡片是否有错误提示；
3. 页面是否重新打开并产生了新请求；
4. 插件设置是否正确。

仍无法解决时，请到对应插件的 GitHub 仓库提交 Issue，附上应用版本、插件版本、复现步骤和错误提示。提交前请隐藏 Cookie、账号等隐私信息。

开发插件请查看[插件开发指南](../development/plugins.md)。

## 业务操作

插件提供业务操作时，可直接点击资源行中的按钮，例如“抓取并下载”。先打开对应网页，按需登录；多个匹配页面时会弹出选择框。抓取进度与错误显示在资源列表，下载和合并进度在任务中心查看。

需要填写参数、批量调用或查看历史时，在插件卡片中展开“高级操作”并选择操作。这里也可以设置是否允许自动化调用，配置方法见 [CLI 与 MCP](automation.md)。
